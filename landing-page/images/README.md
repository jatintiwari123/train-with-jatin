# Photos go here

Replace these with your own photos. **Keep the same file names** so you don't
have to touch any code.

| File name        | Where it shows            | Best size (approx) |
|------------------|---------------------------|--------------------|
| `coach.jpg`      | Big hero photo (top)      | 800 × 1000 (portrait) |
| `about.jpg`      | "About me" section        | 800 × 800 (square) |
| `result-1.jpg`   | Transformation 1          | 600 × 800 |
| `result-2.jpg`   | Transformation 2          | 600 × 800 |
| `result-3.jpg`   | Transformation 3          | 600 × 800 |

How to replace a photo:
1. Rename your photo to match the name above (e.g. `coach.jpg`).
2. Drop it into this `images/` folder (overwrite the old one).
3. Refresh the page — done.

Until you add real photos, a styled placeholder is shown automatically.
